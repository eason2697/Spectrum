# 政治光譜地圖 (Political Spectrum Map)

這是一個基於 Web 技術開發的互動式政治光譜可視化專案。透過二維座標系統（X 軸：經濟左右；Y 軸：社會威權/自由），呈現全球歷史與當代的意識形態、政治人物及重要政黨。

## 🌟 專案特點

- **多元數據維度**：收錄超過 80 種意識形態（Ideologies）、重要歷史人物（Figures）以及當代各國政黨（Parties）。
- **互動式測驗**：內建精心設計的政治傾向測試題庫，根據用戶回答即時計算光譜座標。
- **精準政治定位**：數據座標參考政治學經典理論與當代政經脈絡（如波布主義定位於極左威權，無政府資本主義定位於極右自由）。
- **前端數據驅動**：核心邏輯與顯示數據完全解耦，透過 `data.json` 進行統管理。

## 🗺️ 光譜定義

| 軸向 | 負值 (-) | 正值 (+) |
| :--- | :--- | :--- |
| **X 軸 (經濟)** | **左翼 (Left)**：計畫經濟、集體主義、社會福利 | **右翼 (Right)**：自由市場、私有化、去管制化 |
| **Y 軸 (社會)** | **自由/放權 (Libertarian)**：個人自由、去中心化、社會進步 | **威權 (Authoritarian)**：國家秩序、傳統價值、集權管理 |

## 🗂️ 數據結構說明

專案的核心數據儲存於 `/data/data.json`，結構如下：

### 1. 意識形態 (Ideologies)
定義抽象的政治理論，作為地圖的背景底層。
```json
{
  "ideology": "社會民主主義",
  "x": -20, "y": 0,
  "category": "Center",
  "tags": ["當代主流"]
}
```

### 2. 特殊實體 (Special Entities)
包含具體的歷史人物（`figure`）與政黨（`party`），提供更具體的參照點。
- **Figure**：具備歷史代表性的領導者。
- **Party**：具備高度代表性的當代各國政黨（涵蓋台、美、英、日、德、中、韓等）。

### 3. 測驗題庫 (Questions)
每道題目皆包含 `effect_x` 與 `effect_y` 的偏移權重，用於計算使用者位向。

## 🛠️ 開發與貢獻

### 新增政黨或人物
若要新增數據，請修改 `data.json` 中的 `special_entities` 陣列。

**規範注意事項：**
1. **座標權衡**：在新增座標前，請先參考現有鄰近點位（例如：新增北歐國家政黨時，應參考 `北歐模式` 的座標偏移）。
2. **圖片資源**：`avatar` 欄位建議使用具備透明背景的 `.png` 或具代表性的維基百科 SVG 連結。
3. **標籤管理**：請務必填寫 `tags`（如國家名稱、流派），這將有利於前端過濾器的功能實作。

## 🚀 快速開始

1. 複製專案。
2. 使用 Live Server 或任何靜態伺服器開啟 `index.html`。
3. 點擊「開始測試」或直接探索地圖。

## 🎓 政治學導讀

本專案地圖分為四大區塊：

1. **Authoritarian Left (左上)**：主張透過強大的國家機器實現資源重分配。如：史達林主義、毛澤東思想。
2. **Authoritarian Right (右上)**：主張維護傳統秩序與國家權威，並結合資本主義。如：法西斯主義、新保守主義。
3. **Libertarian Left (左下)**：追求社會平等，但反對中央集權。如：無政府共產主義、北歐模式。
4. **Libertarian Right (右下)**：追求極致的個人自由與完全不受干預的自由市場。如：無政府資本主義、古典自由主義。
